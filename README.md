# みんなの うみ（kaken-fish-yourself）

タブレットに 指で さかなを かくと、うつす画面（プロジェクター）の うみで その絵が およぎだす作品。園児むけ。

- **うつす画面** … `index.html`  
  https://ma4130.github.io/kaken-fish-yourself/
- **かく画面（タブレット）** … `draw.html`  
  https://ma4130.github.io/kaken-fish-yourself/draw.html
- **これまでの え** … `gallery.html`（うつす画面の右下ボタンからも開ける）  
  https://ma4130.github.io/kaken-fish-yourself/gallery.html  
  かいた絵を 日ごとに あたらしい順で ならべる。タップで大きく見て1まいずつ保存、日ごと・ぜんぶを zip で保存できる。「うみを からにする」の前の絵も ぜんぶ見られる。

## つかいかた

1. パソコンで うつす画面を ひらき、プロジェクターに うつす（`F` キーか「ぜんがめん」で全画面）。
2. タブレットで かく画面を ひらく（ホーム画面に追加しておくと べんり）。何台でも同時につかえる。
3. うえの ボタンで かたち（さかな・フグ・サメ・タコ・クラゲ）をえらんで、いろを ぬる。
4. 「できた！」を おすと、うみに とびこんで およぎだす。かく画面は すぐ まっさらになり、つぎの子が かける。
5. うつす画面を クリック（タッチ）すると、えさが おちて さかなが あつまってくる。

- うみに いるのは あたらしい 30 ぴきまで。ふえると ふるい さかなから 画面のそとへ でていく（`?max=40` などで変えられる）。
- 「うみを からにする」は うつす画面の中だけ（その時より前の さかなを出さなくなる）。データはけさない。
- 画面右下のボタンは、マウスを うごかすと でてくる。

## URL のオプション

| つけるもの | いみ |
|---|---|
| `?room=ばしょ名` | うみを わける（例：`?room=hoikuen-a`）。うつす画面と かく画面で おなじにする。なしなら `umi`。 |
| `?local` | Firebase をつかわず、おなじブラウザのタブどうしだけで ためす。 |
| `?max=40` | うみに いる かずの上限（うつす画面）。 |
| `?test` | テスト用に `window.__fish` / `window.__draw` をだす。 |

## しくみ

- ビルドなし。`js/shapes.js`（かたち）、`js/draw.js`（かく画面）、`js/screen.js`（うつす画面）、`js/net.js`（通信）。
- 通信は Firebase プロジェクト **kaken-fish** の Firestore（asia-northeast1）。`fish_seas/{room}/fish/{id}` に `{ img(PNGのdata URL), shape, w, h, t }` を追加するだけ。
- ルールは `firestore.rules`（だれでも読めて追加できる。書きかえ・削除はできない）。かえたら Firebase コンソールの Firestore → ルール に貼って公開する。
